# Phase 1 → Phase 2 remediation

Evidence: inspected actual Git version `6385906` of business-app-pane.tsx and settings-screen.tsx, then diffed current Phase 2 source. Phase 1 used searchable Mail records, selectable previews, Inventory stock detail, summary labels, refresh controls and resizable 240–360px panes. Phase 2's desktop-only RemoteContext replaced these with technical capabilities. The browser Demo still retained the original experience.

Restored real-mode business snapshots using the existing services/MCP runtime. Read-only, enabled, understood list tools with valid bounded arguments can populate reusable Mail/Inventory/CRM/orders/invoice/shipment components. Unknown required parameters are never fabricated. No synthetic business records enter real mode. Unrecognized servers show connection health, Ask G-Bot and permission administration. Reviewed vendor mappings bind exact endpoint/tool/schema and require acceptance evidence; no vendors are currently claimed Recommended. Selected data becomes a user-reviewable chat draft, never an automatic write. Freshness is one minute, with explicit refresh and no polling. Revoked permissions prevent results from being displayed.

Tools remain in connection administration, with Select All/Deselect All, mixed selection and enabled counts. Bulk changes never call MCP. Existing per-action approval binding is retained. Long tool and business values wrap inside shrinkable cards. Empty positions now say Add Connection; category is a suggestion independent of slot number. Saved slots remain on downgrade.

Security evidence: Phase 1 had activity visibility, credential removal, clear history and demo reset; it did not have a separate security radio group. Restored those intentions on desktop instead of inventing obsolete controls. Demo runs in an isolated browser session without preload; simulated failures and reset cannot access native services. About restores logo, identity, version, updates and help/legal links. Developer runtime/npm notes are removed from desktop settings. Neutral Dark overrides all structural colors with equal RGB channels; semantic success/warning/error colors remain distinguishable.

Retained: renderer isolation, narrow validated IPC, protected credentials, actual providers/streaming, MCP/OAuth/discovery/permissions/recovery, exact approvals and packaging. Intentionally not restored: browser-storage security claims, simulated production credentials, fake provider data and capability lists as primary workspace content.

Validation: automated snapshot boundary tests cover unknown, permission, disconnected/expired auth, empty, partial, refresh/cache, mapping binding, long content and in-flight revocation. Existing orchestration tests cover consequential approval enforcement. Browser and native validation outcomes are tracked in VALIDATION.md.
